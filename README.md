# 2D Basic Inventory & UI Tooltip System

A collection of UI elements with adaptive properties

## Key Features
* **Drag and Drop:** Full mouse interaction using Unity EventSystems.
* **Item Stacking:** Data management through `ScriptableObject` "passports".
* **Smart Tooltips:** Dynamic UI tooltip positioning that adapts to screen boundaries based on click coordinates.
* **Isolated Mechanics:** Can be used as a placeholder for game environment tests.

## Technical Details
* **Engine:** Unity
* **Language:** C#
